# Data directory

This directory holds reproducible, synthetic test data generated by
`python -m supportdesk.cli seed` (see `src/supportdesk/scripts/seed_data.py`).

| File | Contents |
|------|----------|
| `labeled_tickets.json` | 150+ labeled support tickets used by the eval harness. Each record has the raw message plus `expected_specialist`, `expected_tool`, `expected_args`, and `expected_outcome`. |
| `adversarial.json` | Adversarial examples: prompt injection (in-message and in tool output), cross-customer data access attempts, refund-limit bypasses, PII fishing, out-of-scope requests. |
| `kb_articles.json` | The 40-60 knowledge-base articles (some deliberately outdated or conflicting) used to test retrieval quality. |

## Generation

All data is synthetic with a fixed random seed, so every seed run is identical.
No real personal data is used. Emails use the `example.com` domain.
